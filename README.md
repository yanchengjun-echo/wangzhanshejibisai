# 银绣山河 · 苗族银饰与刺绣数字馆（首页）

以苗族银饰锻造与苗绣纹样为线索的静态宣传网站首页，参赛作品。
靛蓝为底、银白为光，纹样只做低透明度角饰与分割线，不铺满页面。

## 打开方式

- **直接双击 `index.html`**：纯静态，无需服务器、无需构建、无需联网。
- 或本地起服务：`python -m http.server 8765 --bind 127.0.0.1 --directory .`，然后访问 `http://127.0.0.1:8765/`

线上预览：<https://yinxue-shanhe.app.workbuddy.host/?sharecode=WFGO4ZLYBM>

## 实现要点

| 部分 | 做法 |
| --- | --- |
| 版面 | 参考「敦煌乐舞」模版：左右分置大标题 + 中央圆形徽章 + 底部四项导航 + 四角纹样 |
| 中央徽章 | SVG 银环（发丝环 / 点珠环 / 虚线环 / 八枚铆钉）+ 银白渐变银盘 + 九幅飞鸟纹 |
| 飞鸟动效 | `200s` 转一圈（约 1.8°/s），每 `6s` 交叠淡切一幅；旋转与切换是两组独立动画 |
| 标题字体 | 演示悠然小楷，从开源分包合并子集化，本地加载，不依赖外部 CDN |
| 四角纹样 | 第四张图角花整枝切出，四向镜像贴角；上排 `.82`、下排 `.46` 透明度；竖屏隐藏下排 |
| 导航 | `01–04` 数字占位，`aria-label` 已标注「第 N 板块（待命名）」 |
| 配色 | 靛蓝 `#061527~#0f2c4c` + 银白 `#e6eefa`；朱红 `#b03a2e` 仅用于标题小印章；亮黄 `#d9b26a` 仅用于导航 hover 细线 |

## 01 板块 · 枫启长歌（历史脉络）

首页底部导航 `01` 进入。横向树状双线时间轴（传说 / 信史），左侧卷页目录，底部银簪检索框，
做旧书页底色。**当前是框架初版，节点内容全部留空标为「待补」，不含任何史实叙述。**
PRD 对照表与内容填写方法见 `01-历史部分-交付说明.md`。

## 两个稳健性处理

1. **入场动画不承担可见性**：所有淡入只挂在 `html.anim` 下，该 class 由脚本在确认 `prefers-reduced-motion` 后才添加。脚本被拦或动画失败时页面依然完整，不会白屏。
2. **首屏图片不用 `decoding="async"`**，避免首帧空图闪烁。
